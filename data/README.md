# Dados

Coloque o arquivo `creditcard.csv` do Kaggle nesta pasta:

```text
data/raw/creditcard.csv
```

Dataset recomendado:

- Nome: Credit Card Fraud Detection
- Fonte: Kaggle / MLG-ULB
- Link: https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud
- Alvo: `Class`

Se o CSV ainda nao existir, o pipeline cria uma base sintetica pequena para desenvolvimento local. A base sintetica serve apenas para validar codigo, interface e fluxo do projeto.
